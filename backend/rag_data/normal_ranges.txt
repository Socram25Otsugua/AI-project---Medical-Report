NORMAL ADULT VITAL RANGES (REFERENCE)

Heart rate:
- Typical resting adult: 50-80 bpm
- Concerning if persistently <50 or >120 bpm in acute context

Respiratory rate:
- Typical adult: 12-20 /min
- Concerning if <10 or >25 /min

SpO2:
- Typical: >=95% on room air
- Urgent concern if <92%
- Critical concern if <=90%

Blood pressure:
- Typical: around 90-140 systolic and 60-90 diastolic
- Shock concern when systolic <90, especially with perfusion changes

Temperature:
- Typical: about 36.0-37.8 C
- Hypothermia concern: <35 C
- Fever concern: >=38 C
- 39 C should be interpreted as fever/hyperthermia (context-dependent), not hypothermia

Capillary refill:
- Typical: <=2 sec
- Delayed refill may indicate impaired perfusion

MARITIME TRAINING NOTE
- Interpret values together with symptoms, trend, and scenario constraints.
